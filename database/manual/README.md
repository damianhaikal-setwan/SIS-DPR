# SQL manual/warisan

Dua file SQL ini berasal dari paket SIS-DPR sebelumnya dan **bukan** migrasi Supabase CLI otomatis. Jangan dipindahkan tanpa pemeriksaan ke `supabase/migrations/` atau dijalankan ulang pada database produksi yang sudah menggunakannya.

Periksa skema aktual, dependensi, checksum dan migrasi yang sudah diterapkan terlebih dahulu. Dokumen asal tidak menyertakan skema database dasar dan beberapa migrasi DPA.
